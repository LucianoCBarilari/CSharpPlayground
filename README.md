# CSharpPlayground

Repositorio de practica para algoritmos, estructuras de datos, patrones y ejercicios varios en C#.

## Estructura
- `CSharpPlayground/Algorithms/` algoritmos
- `CSharpPlayground/DataStructures/` estructuras de datos
- `CSharpPlayground/Patterns/` patrones de diseno
- `CSharpPlayground/Math/` matematica discreta y utilidades
- `CSharpPlayground/Practice/` retos sueltos
- `tests/` pruebas unitarias
- `benchmarks/` comparativas de rendimiento
- `docs/` notas y explicaciones breves
- `scripts/` utilidades (datasets, generadores, etc.)

## Convenciones rapidas
- Un archivo por ejercicio/clase.
- Nombres claros y consistentes.
- Agrega una breve descripcion arriba de cada ejercicio.
