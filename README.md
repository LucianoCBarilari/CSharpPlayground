# CSharpPlayground

Practice repository for algorithms, data structures, design patterns, and core C# concepts.  
The goal is to provide a modular playground to experiment, learn, and validate ideas through code and tests.

## Project Structure

- `CSharpPlayground/Slices/Algorithms/`  
  Algorithm implementations and traversal experiments.

- `CSharpPlayground/Slices/Patterns/`  
  Design pattern implementations (e.g., Composite).

- `CSharpPlayground/Slices/LanguageFeatures/`  
  Exploration of C# language features (delegates, extensions, operators, etc.).

- `CSharpPlayground/Slices/Exercises/`  
  Standalone practice exercises.

- `CSharpPlayground/Slices/StudentGrades/`  
  Sample domain used for testing and validation scenarios.

- `tests/CSharpPlayground.Tests/`  
  Unit tests covering different slices.

- `CSharpPlayground/Slices/TestingDojo/`  
  Testing practice area with a guided progression using xUnit.

- `CSharpPlayground/Program.cs`  
  Slice router entry point.
---

## Conventions

- One class or exercise per file.
- Use clear and consistent naming.
- Add a brief description at the top of each exercise.
- Prefer small, focused implementations.

---

## Testing Dojo

This repository includes a **Testing Dojo** focused on improving testing skills through guided practice.

The dojo follows a **tutor-first approach**, where:

* The tutor guides instead of providing full solutions.
* The focus is on test design, naming, and behavior validation.
* Progress is incremental, emphasizing small and clear steps.

👉 [Go to Testing Dojo](CSharpPlayground/Slices/TestingDojo/)
