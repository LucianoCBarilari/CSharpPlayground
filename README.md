# CSharpPlayground

Practice repository for algorithms, data structures, design patterns, and assorted C# exercises.

## Structure
- `CSharpPlayground/Algorithms/` algorithms
- `CSharpPlayground/DataStructures/` data structures
- `CSharpPlayground/Patterns/` design patterns
- `CSharpPlayground/Math/` discrete math and utilities
- `CSharpPlayground/Practice/` standalone challenges
- `tests/` unit tests
- `benchmarks/` performance comparisons
- `docs/` notes and short explanations
- `scripts/` utilities (datasets, generators, etc.)

## Quick Conventions
- One file per exercise/class.
- Clear and consistent naming.
- Add a brief description above each exercise.
